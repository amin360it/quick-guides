0.1 What is Midjourney?

Midjourney is a generative AI art tool that creates images from natural language descriptions. It operates primarily through Discord and has become popular for creating artistic, surreal, and imaginative visuals.

0.1.1 Art Styles

Midjourney supports various art styles including:

  • Realistic photography
  • Concept art and illustration
  • Abstract and surreal art
  • Architectural and interior design
  • Logo and icon design

    • 0.1.2 Key Parameters

    /imagine prompt: a cyberpunk city night, --ar 16:9 --v 6 --style raw

    0.2 Getting Started

    Getting started with Midjourney requires joining the Discord server and using the /imagine command.

    0.2.1 Discord Integration

    Midjourney operates exclusively through Discord. Users must:

    1. Join the official Midjourney Discord server
    2. Subscribe to a plan (Basic, Standard, or Pro)
    3. Use the /imagine command followed by a text description

    1.1 Prompt Structure

    Effective Midjourney prompts follow a structured format for best results.

    1.1.1 Basic Prompt Format
