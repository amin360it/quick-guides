0.1 Why Docker Compose?

Docker Compose is a tool for defining and running multi-container Docker applications. Using a docker-compose.yml file, you can configure your application's services, networks, and volumes.

Multi-Container Applications

Instead of managing multiple Docker commands, Docker Compose lets you define all services in a single file. This makes it easy to orchestrate complex applications.

Declarative Configuration

The docker-compose.yml file uses YAML syntax to declaratively describe application services. This makes the configuration human-readable and version-controllable.

0.2 docker-compose.yml File

The docker-compose.yml file follows a specific structure. Here's a minimal example:

version: '3.8'
services:
  web:
    image: nginx:alpine
    ports:
      - "80:80"
  db:
    image: postgres:13
    environment:
      POSTGRES_PASSWORD: example

Version Key

The version key specifies the Compose file format version. Version 3.x includes features like networks, volumes, and environment variables.
