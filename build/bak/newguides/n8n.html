0.1 What is n8n?

n8n is a workflow automation tool that connects APIs, databases, and services with a visual builder. It is source-available and can be self-hosted or used in the cloud.

0.1.1 Source-Available

n8n is source-available under the fairly-paid license, allowing free use for personal and small team workflows while offering commercial licensing for larger deployments.

0.1.2 Self-Hosted vs Cloud

# Self-hosted via Docker
docker run -p 5678:5678 -e n8n_BASIC_AUTH_ACTIVE=true -e n8n_BASIC_AUTH_USER=admin -e n8n_BASIC_AUTH_PASSWORD=password n8nio/n8n

1.1 Nodes and Connections

Workflows in n8n are built from nodes. Each node performs a specific function, from HTTP requests to database queries, and nodes are connected by drawing edges between them.

1.1.1 Node Types

n8n includes over 200 pre-built nodes covering categories like:

  • AI and LLMs (OpenAI, Claude, Google Gemini)
  • Databases (PostgreSQL, MySQL, MongoDB)
  • API (HTTP Request, Webhooks)
  • File Systems (Local, SFTP, FTP)
  • Email (SMTP, SendGrid)

1.2 Triggers

Triggers start a workflow execution. Common triggers include:

1.2.1 Cron Trigger

# Run workflow every 5 minutes
{
  "trigger": "cron",
  "cronExpression": "*/5 * * * *"
}

1.2.2 Webhook Trigger

# Trigger workflow via HTTP POST
{
  "trigger": "webhook"
}
