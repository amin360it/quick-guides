How this guide is organised

Static sites are written in HTML and shipped as-is. Dynamic apps generate HTML on the server or client per request. Both have a place in modern web development.

Static development

Pure HTML/CSS/JS, or a static site generator like Hugo, Astro, or Next.js in static mode. Fast to build, fast to deploy, ideal for content-driven sites.

Dynamic development

Server-side rendering with PHP, ASP.NET, or Node.js. Needed when each request is different — user data, forms, dashboards, calendars, or any page that talks to a database.

The mindset: pick the simplest tool that works

Do not use Node.js when a static HTML file would do. Do not write raw PHP when a framework gives you routing, templating, and escaping for free. The simplest tool that satisfies the requirement is the right one.

Tools you will use throughout

A text editor, a local server, and a terminal. For static: any editor + a static file server. For dynamic: XAMPP (PHP), Visual Studio (ASP.NET), or Node + npm.

1.1 Pure HTML/CSS/JS

A folder of .html, .css, and .js files can become a complete website without any build step. Just open index.html in a browser.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Static Site</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Hello from static HTML</h1>
  <script src="app.js"></script>
</body>
</html>

1.2 Static site generators

Static site generators like Hugo, Jekyll, Astro, and Next.js in export mode generate HTML from templates and data at build time. The output is still a folder of HTML, CSS, and JS.

// Astro's blog post page
---
import { getCollection } from 'astro:content';
const posts = await getCollection('blog');
---
<html>
<body>
  <ul>
    {posts.map(p => <li><a href={p.slug}>{p.data.title}</a></li>)}
  </ul>
</body>
</html>

1.3 Hosting static sites

Static sites can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any S3-compatible bucket. No server is required.

2.1 PHP & classic webapps

PHP is still one of the most common server-side languages. A single .php file can contain HTML, CSS, JavaScript, and SQL queries.

<?php
$stmt = $pdo->prepare('SELECT name, email FROM users');
$stmt->execute();
while ($row = $stmt->fetch()) {
  echo '<li>' . htmlspecialchars($row['name']) . '</li>';
}
?>

2.2 ASP.NET & Razor pages

ASP.NET Core with Razor pages is the Microsoft equivalent of PHP templates. Each page has a .cshtml file with a page model that handles GET and POST.

@page
@model IndexModel
<p>Hello <strong>@Model.Name</strong></p>

@{
  public class IndexModel : PageModel {
    public string Name { get; set; }}
  }
}

2.3 Node.js & Express

Node.js with Express is the most common JavaScript server stack. You write routes in JavaScript and serve HTML templates with a view engine like EJS or Pug.

const express = require('express');
const app = express();

app.set('view engine', 'ejs');

app.get('/', (req, res) => {
  res.render('index', { title: 'Home' });
});

app.listen(3000);
