0.1 Why Bun?

Bun is a fast all-in-one JavaScript runtime. It’s built on JavaScriptCore (Safari’s engine), making it significantly faster than Node.js for many operations. Bun combines a runtime, bundler, test runner, and npm client.

Performance

Benchmarks show Bun is 2-5x faster than Node.js for startup time and native API operations. It uses JavaScriptCore (Safari's engine) which has highly optimized JavaScript JIT compilation.

0.2 Installation

Installing Bun is simple:

curl -fsSL https://bun.sh/install | bash
# Or using Homebrew on macOS:
brew install bunx/ouseful/bun

Verification

bun --version
