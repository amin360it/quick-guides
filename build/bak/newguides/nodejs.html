0.1 Why Node.js

Node.js is a JavaScript runtime built on Chrome's V8 engine. It allows JavaScript to run outside the browser, enabling server-side scripting, command-line tools, and network applications. Node.js follows an event-driven, non-blocking I/O model that makes it lightweight and efficient.

JavaScript Outside the Browser

Traditionally, JavaScript ran only in web browsers. Node.js changes this by providing a complete runtime environment. With Node.js, you can:

  • Write server-side applications in JavaScript
  • Create command-line tools and scripts
    • Hello World example: 
    const http = require('http');
const server = http.createServer((req, res) => {
  res.writeHead(200, {'Content-Type': 'text/plain'});
  res.end('Hello World');
});
server.listen(3000, () => {
  console.log('Server running on port 3000');
});

    Performance and Non-Blocking I/O

    Node.js's event loop allows it to handle thousands of concurrent connections with minimal overhead. The non-blocking I/O model means that I/O operations don't block the main thread, enabling high-throughput applications.

    0.2 Setup and Installation

    Installing Node.js is straightforward. You can download the binary from nodejs.org or use a version manager like nvm or fnm.

    Installation Methods

    1. Official Installer: Download the LTS (Long Term Support) version from nodejs.org and run the installer.
    2. nvm (Node Version Manager): nvm install lts to install the latest LTS version.
    3. fnm (Fast Node Manager): fnm install --lts for a faster alternative.

    Verification

    After installation, verify Node.js is working:

    node --version
npm --version

    Essential Global Packages

    Some packages are useful to have globally:

    npm install -g nodemon           # Auto-restart on file changes
npm install -g pnpm               # Faster package manager
npm install -g typescript         # TypeScript support

    1.1 Hello World

    The traditional first program in Node.js. Creates a simple HTTP server that responds with "Hello World".

    HTTP Server

    Node.js has a built-in http module that creates servers. The createServer method takes a request listener function.

    const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, {'Content-Type': 'text/plain'});
  res.end('Hello World\n');
});

server.listen(3000, () => {
  console.log('Server listening on port 3000');
});

    Command-Line Usage

    Run the above example: node server.js

    1.2 The REPL

    The Read-Eval-Print Loop (REPL) is an interactive shell for Node.js. Type node in your terminal to start.

    Basic Usage

    $ node
> const msg = 'Hello Node.js'
> msg.toUpperCase()
'Hello NODE.JS'
> .exit

    npm (Node Package Manager) is the world's largest software registry. It comes bundled with Node.js.

    Initializing a Package

    npm init

    Installing Packages

    npm install lodash
npm install --save-dev jest
