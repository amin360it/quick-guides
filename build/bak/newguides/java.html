0.1 Why Java

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. It is a general-purpose language that lets developers write once, run anywhere (WORA), meaning compiled Java code can run on all platforms that support Java without the need to recompile.

0.1.1 Platform Independence

Java's platform independence comes from the Java Virtual Machine (JVM). Java source code is compiled into bytecode, which the JVM executes. This allows Java applications to run on any device with a JVM, making it ideal for enterprise environments with heterogeneous hardware.

0.1.2 Object-Oriented Design

Java is fundamentally object-oriented. Everything in Java is object-based, supporting the four pillars of OOP: encapsulation, inheritance, polymorphism, and abstraction. This design promotes modular, reusable, and maintainable code.

0.2 Setup and Installation

Installing Java is straightforward. You can download the JDK (Java Development Kit) from adoptium.net or jdk.java.net, or use a package manager.

0.2.1 JDK Installation

  1. Download: Get the LTS (Long Term Support) version from adoptium.net.
  2. Install: Run the installer or use your package manager: sudo apt install openjdk-21-jdk (Debian/Ubuntu) or brew install openjdk (macOS).
  3. Verify: Run java -version and javac -version to confirm installation.

0.2.2 Integrated Development Environment

Popular Java IDEs include IntelliJ IDEA, Eclipse, and NetBeans. These provide code completion, debugging, and project management features.

2.1 Classes and Objects

A class is a blueprint for creating objects. It defines attributes (fields) and behaviors (methods). An object is an instance of a class.

2.1.1 Class Definition

public class Car {
    // Fields (attributes)
    private String model;
    private int year;
    private double price;

    // Constructor
    public Car(String model, int year, double price) {
        this.model = model;
        this.year = year;
        this.price = price;
    }

    // Method
    public String getDetails() {
        return "Car: " + model + " (" + year + ") - $" + price;
    }
}

2.1.2 Object Instantiation

// Create an object from the Car class
Car myCar = new Car("Toyota Camry", 2020, 25000.00);

 // Access methods and fields
 System.out.println(myCar.getDetails());
// Output: Car: Toyota Camry (2020) - $25000.00

2.2 Inheritance

Inheritance allows a class to inherit fields and methods from another class. The class being inherited from is the superclass, and the class that inherits is the subclass.

2.2.1 extends Keyword

// Vehicle is the superclass
public class Vehicle {
    public String color;
    public void honk() {
        System.out.println("Beep beep!");
    }
}

// Car inherits from Vehicle
public class Car extends Vehicle {
    private String model;
    private int year;

    public Car(String model, int year, String color) {
        this.color = color;
        this.model = model;
        this.year = year;
    }

    // Override the honk method
    @Override
    public void honk() {
        System.out.println("Beep beep! - Car edition");
    }
}

3.1 Collections Framework

The Java Collections Framework provides a set of classes and interfaces for storing and manipulating groups of data as objects. Key interfaces include List, Set, and Map.

String first = words.get(0); // "Hello"

// Iterate using for-each
for (String word : words) {
    System.out.println(word);
}

3.2 Streams and Lambda

Java 8 introduced the Streams API for processing sequences of elements in a functional style. Lambda expressions enable concise representation of behavior as methods.

3.2.1 Filtering

import java.util.ArrayList;
import java.util.List;

List words = new ArrayList<>();
words.add("Hello");
words.add("World");
words.add("Java");
words.add("Filter");

// Stream operations
words.stream()
    .filter(w -> w.length() > 5)
    .forEach(System.out::println);
// Output: Hello
// Output: World
// Output: Java

3.3 Exception Handling

Java's exception handling uses try, catch, and finally blocks to handle runtime errors and ensure resources are released.

3.3.1 try-catch-finally

try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero: " + e.getMessage());
} finally {
    System.out.println("This always runs");
}

5 · Database Integration

5.1 JDBC

Java Database Connectivity (JDBC) is an API for connecting and executing queries with databases. It provides methods for querying and updating data.

5.1.1 JDBC Connection

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.Statement;

String url = "jdbc:mysql://localhost:3306/mydb";
String user = "root";
String password = "password";

try (Connection conn = DriverManager.getConnection(url, user, password)) {
    Statement stmt = conn.createStatement();
    ResultSet rs = stmt.executeQuery("SELECT * FROM users");
    while (rs.next()) {
        System.out.println(rs.getString("name") + " - " + rs.getInt("id"));
    }
}

5.2 JPA and Hibernate

Java Persistence API (JPA) is a specification for managing relational data in Java applications. Hibernate is the most popular implementation of JPA.

5.2.1 Entity Class

import javax.persistence.Entity;
import javax.persistence.Id;
import javax.persistence.Table;

@Entity
@Table(name = "users")
public class User {
    @Id
    private int id;
    private String name;
    private String email;

    // Getters and setters
    public int getId() { return id; }
    public void setId(int id) { this.id = id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
}
